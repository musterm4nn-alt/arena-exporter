GitHub backups

Automatically back up conversations and attachments to your private GitHub repository after they are archived. Keep the browser open for uploads; offline changes wait here until GitHub is available.

Create a fine-grained personal access token for only your archive repository, with Contents: read and write. The token is saved in this browser profile, never in your archive.

To back up an existing archive, select its arena-archive folder below. Only conversation folders are imported. New archive writes are backed up automatically after connecting. Paused-period writes can be included by importing again.

Archive location

Conversations are written to Downloads/arena-archive/. Chrome can only write beneath its own download directory, so to see the archive elsewhere, link it: 

ln -s ~/Downloads/arena-archive ~/Documents/arena-archive

Silent writes

Suppresses the download bubble so archiving does not interrupt you. History entries are erased after each write either way. This setting affects the browser's download UI globally while enabled, so it stays off until you turn it on. Chrome-only (downloads.ui / setUiOptions); Firefox always shows the download UI.
