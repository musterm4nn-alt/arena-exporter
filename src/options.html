GOOD TO KNOW

Plaintext, on purpose, on this machine.

The local library holds a bounded copy of each transcript so search and reading work offline. It is never uploaded and never enters GitHub backup. Enabling encrypted archives clears it, because a plaintext index must not sit beside sealed files.

Storage is bounded per conversation (4 MiB of payload, 1 MiB of searchable text). A larger conversation stays readable by exporting it from the popup, but is not indexed here.

GOOD TO KNOW

Local saves come first.

A GitHub outage does not stop the local archive. The queue retries later. A green backup status means a successful upload, not just a connection.

Disconnecting removes the saved token from this profile. Your local files and existing GitHub commits remain available.

CAPTURE & SAVING

Automatically archive completed turns

Save new answers and their available files after the response finishes. You can always choose Save now from the popup.

Quiet downloads

Suppress Chrome's download bubble while enabled. This affects the browser's download UI globally. Firefox keeps its usual download UI.

PRIVATE ARCHIVES

Encrypt saved bundles.

Seal new conversation files with AES-GCM. The password stays in memory only; the browser keeps only KDF parameters and a verifier. Existing encrypted bundles keep their original password.

Password-protected local archives

When locked, new saves pause instead of writing plaintext. Enabling this clears the plaintext local library, because it cannot be encrypted with the archive bundle.
