Archive location

Conversations are written to Downloads/arena-archive/. Chrome can only write beneath its own download directory, so to see the archive elsewhere, link it: 

ln -s ~/Downloads/arena-archive ~/Documents/arena-archive

Silent writes

Suppresses the download bubble so archiving does not interrupt you. History entries are erased after each write either way. This setting affects the browser's download UI globally while enabled, so it stays off until you turn it on. Chrome-only (downloads.ui / setUiOptions); Firefox always shows the download UI.
