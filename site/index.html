WHY IT EXISTS

Arena is where the answer happens. Your archive is where it lasts.

Exports are useful only when they preserve the turns, provenance and failures that made the conversation what it was. Arena Exporter is built around capture correctness first, with readable Markdown and structured JSON on top.

CAPTURE → PRESERVE → EXPORT

Built for the parts ordinary “copy chat” tools miss.

01

Capture at document_start

Observes Arena transport from page startup without consuming the page’s own response streams.

02

Every turn stays a turn

Multi-turn sessions, streamed text, reasoning, tool activity, artifacts and request attempts retain their boundaries.

03

JSON + Markdown

Export a full conversation or the last answer with its triggering prompt. Copy the same selected scope directly.

04

Local conversation archive

Save organized conversation folders through Downloads or the optional native archive integration, with destination-aware indexing.

05

Private GitHub backup

Optionally queue archive snapshots to your own private repository. Failed uploads remain in a persistent retry queue.

06

Diagnostics without credentials

Transport metadata is bounded and filtered; DOM diagnostics redact page text and credential-bearing data before storage.

SUPPORTED ARENA MODES

One capture model, four conversation shapes.

AGENT

Agent

Preserves multi-turn agent messages, streamed reasoning, tool calls/results, actions and workspace artifacts. Orchestrator identity stays unknown unless Arena reveals it.

BATTLE

Battle

Keeps A/B lanes separate across rounds, records vote/result data and only treats revealed model labels as verified identity.

DIRECT

Direct

Captures the selected single lane and public catalog selection metadata without turning a selection identifier into hidden model proof.

SIDE-BY-SIDE

Side-by-Side

Preserves both selected lanes over multiple turns, including per-lane files, tools and unverified selection provenance.

ARCHIVE WORKFLOW

Useful online. Still useful offline.

  1. 1

    Talk on Arena

    The extension listens from page startup and keeps tabs and initiating requests isolated.

  2. 2

    Save locally

    Automatic completed-turn saves or Save now write the conversation and available files to the configured archive destination.

  3. 3

    Export when you need it

    Choose JSON for structured data or Markdown for a readable record; use full conversation or last answer scope.

  4. 4

    Back up on your terms

    Connect a private GitHub repository only if you want remote backup. Local saving remains independent.

PRIVACY MODEL

Conversation content is valuable. Credentials are not archive content.

Arena Exporter is local-first. It structurally filters authorization data, cookies, CAPTCHA values, token/key fields, credential-bearing URLs, nested JSON secrets and private-key material before diagnostics or transport metadata are persisted or exported.

Exports still contain the conversation and files you asked to preserve; privacy filtering is not general anonymization.

ENGINEERING SHAPE

Transport details stay separate from conversation truth.

Interception→Parsing→Session correlation→Reconstruction→Export / archive

Request attempts, model provenance, privacy filtering, persistence, archive sinks, backup and UI state have separate modules so a visual change does not redefine captured data.

GET STARTED

Load the real extension from the repository.

CHROME / CHROMIUM
  1. Run the release build or use the repository root.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the Chrome package folder.
  4. Reload the Arena tab.
FIREFOX
  1. Run the release build to regenerate the Firefox package.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select firefox/manifest.json.
  4. Reload the Arena tab.
